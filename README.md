## Цель

Создать многостраничный сайт на чистом HTML и CSS без единой строки JavaScript. Навигация, темизация, слайдер и вкладки реализованы только через CSS-механики (`input[type=radio]`, `input[type=checkbox]`, псевдоклассы `:checked ~ `).

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, псевдоклассы, CSS-переменные)
- Без фреймворков и библиотек

## Возможности

- Многовкладочная навигация (Главная, Секции, Расписание, Калькулятор, Запись) — через radio-инпуты
- Hero-слайдер — через radio-инпуты и CSS transitions
- Тёмная/светлая тема — через checkbox + CSS-переменные
- Адаптивная вёрстка: мобильное меню через checkbox
- Калькулятор-заглушка в отдельной вкладке

## Запуск

Открыть `index.html` в браузере напрямую — сервер не нужен.
