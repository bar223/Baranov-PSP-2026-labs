## Цель

Добавить к сайту из ЛР 1 динамическое поведение на JavaScript: управление DOM, обработка событий, работа с данными без перезагрузки страницы.

## Технологии

- HTML5
- CSS3
- JavaScript (ES6+, без фреймворков)

## Что добавлено относительно ЛР 1

- Карточки секций генерируются из массива данных через JS (`document.createElement`, `insertAdjacentHTML`)
- Добавление новой карточки по кнопке — генерация случайной секции
- Удаление карточки — делегирование событий
- Фильтрация карточек по названию в реальном времени
- Калькулятор с полной логикой: базовые операции, унарные функции (√, x², !), история вычислений

## Запуск

Открыть через расширение **Live Server** в VS Code: правой кнопкой на `index.html` → «Open with Live Server».
